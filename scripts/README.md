# Scripts

Produced with the prompt in [`../prompts/script.md`](../prompts/script.md).

## Batch 1 — streamer economy

Three scripts that share a niche and argue with each other slightly, which is what
you want from a block: someone who finishes one has a reason to start the next.

| Script | Thesis | Publish |
| --- | --- | --- |
| [`sidemen-group-moat.md`](sidemen-group-moat.md) | The group is a structural moat a solo creator can't build at any budget. | First — the recognisable name does the discovery work. |
| [`the-access-business.md`](the-access-business.md) | Audiences buy access to a person, and access can't be scaled. | Second — the deeper cut for people who came back. |
| [`the-click-ate-the-content.md`](the-click-ate-the-content.md) | The thumbnail isn't packaging, it's the first sentence of the video. | Last — fully evergreen, no names or dates to decay. |

Each file carries the narration (~1,500 words, ~10 minutes at 150 wpm), a loop map
with timestamps, eight ranked title options, a thumbnail direction, and a
**Before you record** section listing what to verify.

## House rules for these scripts

- **No invented specifics.** No numbers, dates, or counts unless verified from a
  primary source. Placeholder-free is better than confident and wrong — this niche
  fact-checks in the comments.
- **No named individuals as cautionary tales.** Structural arguments don't need a
  villain, and a real person's burnout is not b-roll.
- **Narration only.** No shot lists or stage directions in the script body; that
  lives in the notes underneath.
