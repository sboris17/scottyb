# clips/

Drop your own footage here, named by slot:

| file | slot | moment |
|---|---|---|
| `parley01.mp4` | PARLEY CLIP 01 | Elizabeth — "I invoke the right of parley!" |
| `parley02.mp4` | PARLEY CLIP 02 | Pintel & Ragetti — "parlili... parsnip... par-le-nee?" |
| `parley03.mp4` | PARLEY CLIP 03 | Jack — "The word is parley." |
| `parley04.mp4` | PARLEY CLIP 04 | Barbossa — "more what you'd call guidelines" |

Then run `python3 splice.py`. Any slot without a file keeps its placeholder
slate, so you can add them one at a time.

Nothing in here is committed — this repo ships no copyrighted footage, and
these files stay local to you. See `../README.md`.
